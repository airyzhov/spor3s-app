# Розыгрыш 10.10: кнопка «Участвую», новые призы, рассылка

Дата: 2026-09-28
Статус: согласовано в чате (ответы владельца от 28.09). Меняет §2 и §11 спеки
`2026-09-24-raffle-10-10-design.md`; сроки, число победителей и выбор победителей — прежние.

## 1. Правила

- **Участник** = хотя бы одно подписочное задание (`sc_transactions.source_type` из
  `subscribe_telegram / subscribe_youtube / subscribe_instagram`, до конца приёма; выполненные до старта
  тоже в счёт) **и** нажатая кнопка «✋ Участвую» (строка `raffle_entries`). Автоматически никто не участвует.
- «Участвую» можно нажать только в окне приёма и только после задания.
- **Приз** по своим друзьям: без друзей — 1 добавка на выбор, 1–2 друга — 2 добавки на выбор,
  3 и больше — комплекс добавок.
- **Друг** — как раньше (приглашение в окне, новый пользователь Telegram), но «открыл приложение»
  теперь значит `ai_agent_status.last_activity > created_at`. Строку `ai_agent_status` для каждого
  нового пользователя создаёт триггер БД `trigger_create_ai_agent_status` (оба поля = NOW()), а
  `/api/init-user` при каждом входе в мини-апп ставит `last_activity = now`. Раньше засчитывался и тот,
  кто только нажал Start в боте, а сообщение пригласившему о новом друге не уходило вообще
  (`seenBefore` в init-user всегда был true).

## 2. Данные

`raffle_entries.sql` (владелец выполняет в Supabase → SQL Editor до выкладки):

- `raffle_entries (raffle_id, user_id, created_at)`, unique `(raffle_id, user_id)` — кто нажал «Участвую»;
- `raffle_notices (raffle_id, user_id, kind, sent_at)`, unique `(raffle_id, user_id, kind)` — кому бот уже
  отправил рассылку о розыгрыше (`kind = 'announce'`), чтобы повторное нажатие не слало дважды.

Пока таблиц нет — `joined = false` у всех, кнопка отвечает «Скоро», рассылка недоступна.

## 3. Кабинет

Карточка «🎁 Розыгрыш 10.10»:

1. ⬜/✅ «Выполни задание на подписку в кабинете» + «К заданиям →»;
2. ⬜/✅ «Нажми «Участвую»» + кнопка «✋ Участвую» (после задания; до него — «Сначала выполни задание»);
3. «👥 Друзей: N» + «Пригласить» — всегда: друзья увеличивают приз;
4. после нажатия: «✅ Ты участвуешь! Если выиграешь — {приз}. Пригласи ещё N — будет {следующий приз}».

Заголовок и строка на главной: «N из 2 условий» / «✅ Ты участвуешь». Ссылка
`https://ai.spor3s.ru/?open=raffle` открывает кабинет с раскрытой карточкой (как `?open=course`).

## 4. Бот

- Первое задание в окне приёма, «Участвую» не нажато → «✅ Задание выполнено! Чтобы участвовать в розыгрыше
  10.10, нажми «✋ Участвую»…» + кнопки «🎁 Открыть розыгрыш» (`?open=raffle`) и «👥 Пригласить друзей».
- Засчитался друг: участник (задание + «Участвую») — «🚀 Друг засчитан…» на 1-м и 3-м друге (приз вырос);
  не нажал «Участвую» — на 1-м друге напоминание нажать.
- **Рассылка** (кнопка в админке «📣 Рассказать о розыгрыше (N)», с подтверждением): всем пользователям
  Telegram, кто ещё не нажал «Участвую» и кому рассылка ещё не уходила. Текст — как участвовать и призы;
  у выполнивших задание — «✅ Задание у тебя уже выполнено — осталось нажать «Участвую»». Отправляется
  только по нажатию владельца; итог — отправлено / не дошло (не запускали бота).

## 5. Админка

Колонка «Нажал «Участвую»», счётчик «Участвуют (задание + «Участвую»)», в CSV — колонка «Участвую»;
в розыгрыш 12.10 идут только участники.

## 6. Проверка

Юнит-тесты правил (призы, участие, «открыл приложение», сообщения), сервера (нажатие, рассылка без повторов —
поддельная база) и карточки; превью; после выкладки — сквозная проверка на временных пользователях.
