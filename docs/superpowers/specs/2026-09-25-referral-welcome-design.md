# Приглашение: 100 SC другу сразу и «Вас пригласил» в кабинете

Дата: 2026-09-25
Статус: ответы владельца от 25.09 — SC сразу получает только приглашённый; только тот, кто ещё не покупал

## 1. Цель

Друг, пришедший по реферальной ссылке, получает приветственные 100 SC сразу — а не после первого
оплаченного заказа — и видит в кабинете, кто его пригласил.

## 2. Как сейчас

- Ссылка `https://t.me/spor3sbot?start=<telegram_id>` → бот (`handleReferralStart` в `tg-bot/bot.ts`)
  создаёт строку `referrals` (`pending`, первая ссылка побеждает) и пишет «🎁 Вас пригласил @X! За первый
  оплаченный заказ вы получите 100 SC…».
- 100 SC приглашённому (`referral_welcome`) и 5% пригласившему (`referral_cashback`) начисляются, когда
  заказ в админке становится оплаченным (`processReferralOnPaid` в `app/api/admin/orders/route.ts`).
  Приветственный бонус там проверяет только «не получал ли уже» — постоянный покупатель, введший чужой код,
  тоже получит 100 SC.
- Кто пригласил, видно только в форме заказа (`/api/referral-stats` → `invitedBy`), в кабинете — нет.
- В базе 5 приглашённых: все `pending`, все открывали магазин, ни одного оплаченного заказа, начислений нет.

## 3. Правила

- 100 SC получает только приглашённый. Пригласившему — как раньше: 5% с каждого оплаченного заказа друга.
- Один раз на человека и только тому, у кого нет оплаченных заказов (`paid` / `shipped` / `completed`).
  Постоянный покупатель по чужой ссылке 100 SC не получает; привязка к пригласившему и 5% — как раньше.
- Правило одно для обоих путей: ссылка из бота и реф-код, введённый в форме заказа.

## 4. Решение

### Начисление — при входе в магазин

`grantReferralWelcome(userId, { orderId? })` в `lib/referral.ts`:

1. нет строки `referrals` с `referred_user_id = userId` → ничего;
2. у пользователя уже есть `referral_welcome` → ничего;
3. есть оплаченные заказы (не считая `orderId`, если передан) → ничего;
4. `creditSC`: 100 SC, `source_type = 'referral_welcome'`, `source_id = orderId ?? id строки referrals`,
   описание «Приветственный бонус: вас пригласил @X».

Вызовы:

- `/api/init-user` — при каждом входе в мини-апп, после создания пользователя; ошибка пишется в лог и
  вход не валит. Друг жмёт «🛒 Открыть магазин» в сообщении бота — SC уже на балансе.
- `processReferralOnPaid` — вместо нынешней ветки «приветственные 100 SC»: код, введённый в форме, или
  заказ через бота до первого входа в магазин.

Отвергнуто:

- начислять в боте при `/start` — бот отдельный проект и не видит `lib/`: пришлось бы копировать
  `creditSC` без пересчёта уровня, а пятеро уже приглашённых остались бы без бонуса;
- бот вызывает защищённый API сайта — лишний эндпоинт и подпись запросов ради того же результата.

### Бот

Текст ответа на ссылку — в `tg-bot/replies.ts` (`referralWelcomeText(refName, eligible)`); бот проверяет,
есть ли у приглашённого оплаченные заказы:

- не покупал: «🎁 Вас пригласил @X! Дарим вам 100 SC (= 100 ₽ скидки) — они уже ждут в кабинете.
  Списать можно при заказе, до 30% суммы. Выбирайте грибные добавки 👇» + «🛒 Открыть магазин»;
- покупал или проверка не удалась: «🎁 Вас пригласил @X! Выбирайте грибные добавки 👇» — без обещания SC.

### Кабинет

- `getInvitedBy(userId)` в `lib/referral.ts` → `{ name, welcomeSc } | null`: `name` — `@username`
  пригласившего или «друг», `welcomeSc` — сумма начисленного `referral_welcome` (0, если ещё нет).
  Её отдают `/api/home-summary` (новое поле `invitedBy`) и `/api/referral-stats` (вместо своего кода);
  форма заказа показывает `invitedBy.name` — полный Telegram ID пригласившего больше не выводится.
- Панель SC (`ScStatus`) — под строкой баланса, видно без раскрытия:
  «🤝 Вас пригласил @web3grow · 🎁 +100 SC» (вторая часть — только если бонус начислен).

### Тексты

- Раздел «🎁 Реферальная система»: «Друг сразу получает 100 SC, а вы — 5% с каждого его оплаченного заказа».
- Текст «Поделиться» (`lib/referralLink.ts`): «…получишь 100 SC (100₽) на первый заказ!» →
  «…сразу получишь 100 SC (= 100 ₽ скидки)!».

## 5. Уже приглашённые

Пятеро приглашённых без оплат получат по 100 SC при следующем входе в магазин — всего 500 SC.
Отдельного скрипта не нужно.

## 6. Ссылка в Telegram (без изменений в коде)

Код приглашения попадает к боту, только если ссылку открыть нажатием — в сообщении, из браузера или по
QR-коду. Если вставить ссылку в поиск Telegram, он найдёт бота по имени и откроет чат без кода — привязки
не будет. Свою ссылку со своего аккаунта не проверить: бот ответит «Это ваша собственная реферальная ссылка».

## 7. Проверка

- `lib/__tests__/referralWelcome.test.ts` (база в памяти, как в `recalcOrderTotals.test.ts`):
  начисляет 100 SC один раз; без приглашения — ничего; с оплаченным заказом — ничего; повторный вызов
  не задваивает; при оплате не считает сам оплачиваемый заказ; `getInvitedBy` — имя и сумма бонуса.
- `tg-bot/__tests__/replies.test.ts`: оба текста бота.
- `ScStatus` (RTL): строка «Вас пригласил … · +100 SC» есть с `invitedBy` и нет без него.
- Изолированное превью: кабинет приглашённого на ширине телефона.
- Выкладка: сайт + пересборка бота.
