# Поле «Код друга» в кабинете

Дата: 2026-09-25
Статус: согласовано в чате (ответы владельца от 25.09)

## 1. Цель

Человек, пришедший без реферальной ссылки, сам вводит в кабинете код пригласившего и сразу получает
приветственные 100 SC — по правилу из `2026-09-25-referral-welcome-design.md`.

## 2. Правила (ответы владельца)

- Код — `@username` (регистр не важен) или числовой Telegram ID пригласившего. Телефон не принимаем:
  перебором номеров можно было бы узнавать, кто из них покупатель.
- Поле видят только настоящие пользователи Telegram (числовой `telegram_id`), у которых нет
  пригласившего и нет оплаченных заказов.
- Пригласившим может быть только настоящий пользователь Telegram — «заочные» записи `pending-…`
  из реф-кодов заказов не в счёт.
- Первая привязка побеждает; свой код ввести нельзя.
- После привязки — `grantReferralWelcome` (100 SC сразу, один раз).

## 3. Решение

`lib/referral.ts`:

- `parseInviterCode(raw)` → `{ kind: 'telegram_id' | 'username', value } | null` (без сети);
- `ownReferralCode(user)` → `@username`, иначе числовой Telegram ID, иначе `null` (без телефона);
- `canEnterInviterCode(userId)` — Telegram-пользователь, без пригласившего и без оплаченных заказов;
- `claimReferral(userId, code)` → `{ name, welcomeSc }` или `ReferralClaimError(status, message)`:
  400 «Введите @username или Telegram ID друга», 403 «Код друга можно ввести в приложении из Telegram»,
  404 «Не нашли такого пользователя — проверьте код», 400 «Это ваш собственный код — отправьте его
  друзьям», 409 «Пригласивший у вас уже есть», 409 «Код друга можно ввести только до первой покупки».
  Username ищется через `ilike` с экранированными `_` и `%` (иначе `ryzhov_ai` совпал бы с `ryzhovXai`).

API: `POST /api/referral-bonus` `{ user_id, code }` → `{ success, invitedBy }` (старый нерабочий код
маршрута — писал в легаси-таблицы и выбирал несуществующую колонку — заменяется).
`/api/referral-stats`: `referralCode = ownReferralCode(user)`, новое поле `canEnterInviterCode`.

Кабинет, раздел «🎁 Реферальная система»:

- есть пригласивший — строка «🤝 Вас пригласил @X · 🎁 +100 SC»;
- можно ввести код — форма `InviterCodeForm`: «🤝 Вас пригласил друг?», поле «@username или ID
  друга», кнопка «Получить 100 SC», ошибка под полем; после успеха — перечитать статистику и панель SC;
- пока форма доступна, свёрнутый заголовок раздела: «код друга → +100 SC» вместо «приглашено: N»;
- подпись своего кода: «Или ваш код — друг введёт его в кабинете или при заказе:».

Форма заказа не меняется.
