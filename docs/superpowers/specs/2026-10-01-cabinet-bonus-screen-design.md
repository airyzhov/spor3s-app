# Кабинет одним экраном: баланс, розыгрыш, «Как получить SC»

Дата: 2026-10-01
Статус: согласовано в чате (вариант 1 «только экран», «да, делай» 01.10)

## 1. Цель

Упростить кабинет по примеру бонусного экрана Walt: одно большое число (баланс SC), одна главная
карточка с дедлайном и прогрессом (розыгрыш), один список «Как получить SC». Сейчас — шесть
сворачиваемых блоков, задания встречаются дважды (плашка и раздел), приглашение — третьим блоком,
баланс мелкий и спрятан. Верхнюю навигацию магазина не трогаем; вкладка остаётся «🎁 Кабинет»
(бот в сообщениях зовёт «в кабинет»).

## 2. Экран сверху вниз

1. **Баланс** (`BonusHero`, вместо `ScStatus`): «Ваши SC», крупно число, «= N ₽ скидки · до 30% суммы
   заказа»; строка «До уровня X: ещё …», если следующий уровень есть; три кнопки — уровень
   («🌱 Новичок ›», окно уровней как сейчас), «🧾 История ›» (раскрыть историю ниже и прокрутить к ней),
   «❓ Как это работает» (окно с правилами SC). Строка «🤝 Вас пригласил … · 🎁 +100 SC» остаётся.
2. **Розыгрыш** (`RaffleBanner`) — всегда раскрыт, без «Условия ▼»:
   - плашка «⏳ Ещё N дней» (меньше суток — «⏳ Последний день»);
   - шаги с галочками: «Задание» → «Участвую» → «👥 N друзей»;
   - приз: участнику — «Если выиграешь — … Пригласи друга — будет …» (как сейчас), до участия —
     «Приз сейчас: …»;
   - одна главная кнопка: нет задания — «🎯 Выполнить задание (+30 SC)» (прокрутка к списку);
     задание есть — «✋ Участвую»; участник — «👥 Пригласить друга — приз вырастет» (копирует ссылку);
   - гость без Telegram — «участвовать можно только через Telegram», без кнопок;
   - «Условия ›» раскрывает правила: призы по друзьям, кто считается другом, сроки;
   - «Приём закрыт» и «Итоги» — как сейчас, без сворачивания.
3. **«Как получить SC»** (`EarnList`) — вместо плашки «Получи 90 SC», раздела «🎯 Задания»,
   раздела «🎁 Реферальная система» и «Как заработать SC» в панели:
   - три подписки: справа «Подписаться» → после перехода в канал «Получить +30» → выполнено «✅ +30»;
   - «👥 Пригласи друга — другу 100 SC, тебе 5% с его заказов» — нажатие раскрывает всё, что было
     в «Реферальной системе» (`ReferralPanel`: условия, кто пригласил / поле «Код друга», ссылка,
     «Скопировать», «Поделиться», свой код, статистика, приглашённые);
   - «🛒 Покупки — 1 SC за каждые 100 ₽» — в каталог;
   - «🍄 Отчёт о самочувствии — +25 SC в неделю, +50 SC за 4 отчёта в месяц» — только если доступен
     курс; ведёт к разделу курса.
4. Ниже без изменений: «🧾 История SC», «Мой курс», привычка (тестировщики), «📦 Мои заказы».

Кнопки бота ведут как раньше: `?open=raffle` — к розыгрышу, `?open=course` — к курсу, `?open=sc` —
к истории (раскрыта), переход к заданиям — к списку «Как получить SC». Строка розыгрыша на главной
(`RaffleTeaser`) не меняется.

Заодно в админке: колонка «SC клиента» в заказах перечитывается сразу после смены статуса
(01.10 владелец увидел 0 SC у заказа, которому только что начислились 8 SC).

## 3. Решение

- `lib/raffle.ts`: `raffleDaysLeftLabel(now)` → «⏳ Ещё 9 дней» / «⏳ Последний день» / `null`
  после конца приёма (дни — вверх до целого, граница — `RAFFLE.endsAt`).
- `app/(client)/BonusHero.tsx` — данные `/api/home-summary` (как у `ScStatus`), перечитывает по
  `refreshKey`; проп `onOpenHistory`. `app/(client)/HowItWorksModal.tsx` — окно в `body` (как
  `LevelsModal`): 1 SC = 1 ₽, до 30% заказа; способы заработать с суммами; уровни дают скидку.
- `app/(client)/EarnList.tsx` — список без своих запросов: состояние подписок, «открыл канал»,
  загрузка и обработчики приходят из `RoadMap`; панель приглашения — `children`.
- `app/(client)/ReferralPanel.tsx` — перенос разметки раздела «Реферальная система» из `RoadMap`.
- `app/(client)/RaffleBanner.tsx` — новая раскладка карточки; загрузка, «Участвую», `RaffleTeaser`
  без изменений.
- `CabinetSection`: `openSignal?: number` — раскрыть при каждом изменении (кнопка «История» в шапке
  раскрывает раздел повторно, даже если его свернули); `ScHistorySection` пробрасывает.
- `RoadMap.tsx`: новый порядок; прокрутка к цели (`tasks`, `raffle`, `course`, `sc`) — прежним
  механизмом с удержанием, пока догружаются данные; проп `onOpenCatalog` (из `AppClient`).
- Удаляются `ScStatus.tsx`, `TasksBanner.tsx` и их тесты (проверки переезжают в `BonusHero`).
- `app/admin/page.tsx`: после смены статуса заказа — перечитать `/api/admin/users-balances`.
